# Dados fictícios para teste do modelo de QA

Todos os registros em `modelo_qa_teste.xlsx` são totalmente fictícios e foram criados apenas para validar futuramente a leitura, as contagens e a análise do agente de Status Report de QA.

Os identificadores `US-FIC-*`, `TC-FIC-*` e `BUG-FIC-*`, descrições, resultados, responsáveis e datas são exemplos sintéticos. Eles não representam projeto, pessoa, execução, incidente ou resultado real. Não use este arquivo como evidência de QA de um projeto.

O arquivo base `modelo_qa.xlsx` permanece como modelo vazio. A cópia de teste mantém as duas abas do modelo e contém uma linha por cenário e uma linha por bug, com um único cenário relacionado a cada bug.
